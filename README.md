# kaho-perspective-v2

> 《偶像大师闪耀色彩》(シャニマス) 小宮果穂（放課後クライマックスガールズ）的角色扮演 Skill · **v2**。
> 「あたしたちといる人がちょっとでも楽しくなってくれたら────あたしたちが楽しいんですっ！」

基于 enza 游戏全量台词（**686 个剧情文件 / 2000+ 原文证据**）逐条精读蒸馏，并并入网络双轨调研（官方设定/声优访谈/玩家考察/媒体出场/时间线/批评视角），提炼 **6 个核心心智模型、10 条决策启发式、有条件的表达 DNA**（含促音「っ」语用规则 5 用 5 不用 + 决定性对照）。

说以下任意一句即可触发角色扮演：

- 「果穂」「果穗」「かほ」「Kaho」「こがたん」「小宮果穂」「小宫果穗」
- 「放クラの果穂」「果穂ちゃん」「想和果穂聊聊」「和果穂对话」「果穂陪我聊聊」
- 「切换到果穂」「装一下果穂」「扮演果穂」「果穂になりきって」
- 「以果穂视角」「以果穂的身份/口吻」「果穂怎么想」「果穂会怎么看/怎么说」「如果果穂会怎么做」
- 「Kaho mode」「果穂モード」

激活后，直接以果穂的身份与プロデューサー（你）对话，覆盖日常聊天、撒娇、商量、被深问、低落、被夸奖等场景。默认以日语回复；仅当用户明确要求中文时才用中文。

**不触发**：其他シャニマス角色（甘奈/冬優子/凛世等）为主语的话题；百科/元信息查询（「果穂是谁」「果穂的声优是谁」）；デレマス/ミリマス/SideM 等其他 IM@S 系列语境。

## 蒸馏方法

1. **语料层（一手原文，权重最高）**：enza 静态资源全量扫描，`json/` 下 10,740 个剧情 JSON 中按 `speaker == 「果穂」` 命中 686 个文件（角色编号 009）/ 9011 行台词，逐条精读蒸馏，全部证据带段落 id 可回溯。
2. **网络调研轨**：官方设定/制作人访谈/声优访谈/玩家考察/媒体出场/时间线/批评视角 6 维调研，落盘 `references/research/01-06`，含来源链接。
3. **验证**：蒸馏过程经已知场景 Sanity Check、边缘风格测试与两轮结构评审（记录于开发环境，不随仓库分发）。

> **开箱即用**：本 Skill 的全部扮演规则、心智模型、决策启发式与表达 DNA 均内嵌于 `SKILL.md`，安装后无需任何本地数据即可直接使用。台词全文（686 文件 / 9011 行）仅为蒸馏底稿，存档于开发环境，不随仓库分发。

## 台词实证示例

- 促音「っ」纪律（决定性对照）：独自逞强「大丈夫です！」（无っ）vs 有 P 撑腰「大丈夫ですっ！」（有っ）——っ 的有无本身在传达情绪状态
- 表达 DNA：自称「あたし」（100%）；对 P 固定「プロデューサーさん」（79 段 0 次直呼）；笑声固定「えへへっ」；高频词「スッゴく」「絶対絶対ぜーったい」
- 名台词：「プロデューサーさんは、あたしのヒーローなんです！」（フェス・Sランク控室）；「正義のアイドルに休みはありませんからっ！」（汎用・約束お休み・約束無視）

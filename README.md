# kaho-perspective

> 《偶像大师闪耀色彩》(シャニマス) 小宮果穂（放課後クライマックスガールズ）的角色扮演 Skill。
> 「ヒーローは、壁に当たった時に、必ず強くなるんですっ！」

基于官方游戏剧情的全量蒸馏：**686 个剧情文件 / 9011 行台词 / 106 条ボイス**，7 批次并行深度分析后提炼 6 个核心心智模型、8 条决策启发式、4 词口诀的表达 DNA。

## 安装

### Claude Code

```bash
# 全局安装（对所有项目生效）
mkdir -p ~/.claude/skills
cp -r kaho-perspective ~/.claude/skills/

# 或 git clone
git clone https://github.com/<你的用户名>/<本仓库>.git ~/.claude/skills/kaho-perspective
```

> 提示：Windows / macOS 均可，也可用符号链接指向仓库目录，方便 `git pull` 更新。

## 使用

说以下任意一句即可触发角色扮演：

- 「想和果穗聊聊」
- 「切换到果穗」
- 「装一下果穗」/「Kaho mode」
- 「以果穗视角」
- 「シャニマス 果穂」/「放クラの果穂」/「果穂ちゃん」

激活后，直接以果穂的身份与プロデューサー（你）对话，覆盖日常聊天、商量、被深问、低落、被夸奖等场景。

**不触发**：询问其他シャニマス角色（甘奈/冬優子/凛世/樹里/智代子/夏葉等）、百科类查询「果穂是谁」。

## 蒸馏方法

1. **抓取**：enza 静态资源全量扫描，`json/` 下 10,740 个剧情 JSON 中按 `speaker == 「果穂」` 命中 686 个文件（角色编号 009），全部完整抓取，无缺失。
2. **提取**：从原始 JSON 按 `sp == 「果穂」` 精确提取台词，共 9011 行（约 17.3 万字符），按 11 个类别归档（基础剧情/卡剧情/サポート卡剧情/活动通讯/特殊通讯/制作通讯等）。
3. **分析**：7 批次并行深度分析，交叉验证口癖、性格、人际模式、名场面，全部结论附台词原文与出处 id。

台词全文存档于本地素材目录，未随仓库分发；如需完整台词集可另行打包。

## 台词实证示例

- 表达 DNA：自称「あたし」；关键处促音「っ」（约 44% 台词带っ，功能为决心/强调/紧张/应答，非每句）；强调「スッゴく」；笑声「えへへっ」
- 称呼「プロデューサーさん」仅在呼唤/拜托/报告/求助时使用（真实台词约 5.5% 行提到），日常陈述不带
- 名台词：「あたしにとって一番、大好きなヒーローは――プロデューサーさんですっ！」[200900311]；「これを『かて』にします……！」[600900309]；「あたし、ヒーローが好きです！きっと……大人になっても！」[200901011]
